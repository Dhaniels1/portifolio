Dashboard de Vendas 2020.

De uma planilha de vendas a um painel interativo, com indicadores, filtros dependentes e visualizações para explorar dados comerciais.

OBJETIVO E CONTEXTO

Transformar registros em informação consultável.

Este painel foi desenvolvido em dupla para uma disciplina de Visualização de Dados. O objetivo foi organizar registros de vendas de 2020 em uma ferramenta gerencial com exploração visual e filtros combinados.

A planilha original é obtida de uma fonte externa indicada no repositório. Isso exige uma etapa de preparação para padronizar os dados antes de construir gráficos e indicadores.

FUNCIONALIDADES

Como a solução funciona

01

Indicadores e evolução

O painel apresenta valores de faturamento, quantidade de vendas e evolução temporal, com visualizações interativas.

02

Filtros encadeados

A escolha de um estado altera as cidades disponíveis, evitando combinações inconsistentes de localidades.

03

Exploração e exportação

Filtros por período, representante, regional, produto e cliente podem ser combinados; os dados filtrados podem ser exportados.

IMPLEMENTAÇÃO

Uma aplicação Python publicada na nuvem.

PythonDashPlotlyPandasGunicornRender

A interface usa Dash, os gráficos são construídos com Plotly e a manipulação dos registros é feita com Pandas. O arquivo dados.py centraliza parte da preparação, e app.py reúne layout e callbacks.

As etapas documentadas incluem conversão de datas e valores monetários, filtragem do ano-alvo, remoção de registros inválidos e cálculo das agregações utilizadas nas visualizações.

O serviço está configurado no Render, que executa a aplicação por meio de Gunicorn. A organização do código mantém parte das responsabilidades de interface e tratamento de dados separadas.

QUALIDADE E TRANSPARÊNCIA

Verificações independentes da planilha externa.

O repositório contém testes com dados sintéticos, permitindo verificar filtros, agregações, tratamento de valores inválidos e dependência Estado → Cidade sem acessar a fonte original durante esses testes.

Essas verificações mostram a consistência das regras programadas, mas não substituem a auditoria da qualidade da base de vendas fornecida para a disciplina.

LIMITES E PRÓXIMAS MELHORIAS

Evoluções possíveis.

Adicionar um relatório reproduzível de tratamento da base, capturas atualizadas dos gráficos, um diagrama de fluxo de dados e exemplos de perguntas gerenciais respondidas pelo painel.

Como a aplicação utiliza hospedagem gratuita, a primeira abertura pode levar mais tempo após períodos de inatividade. Um novo build também depende da disponibilidade da fonte externa da planilha.
