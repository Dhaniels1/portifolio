SOBRE MIM

Aprender na prática é o meu jeito de evoluir.

Sou Daniel Castro, estudante de Gestão da Tecnologia da Informação no IF Sudeste MG — Campus Muriaé. Meu portfólio reúne aplicações desenvolvidas ao longo da formação, com interesse especial em desenvolvimento web, APIs e análise de dados.

EVOLUÇÃO TÉCNICA

Construindo uma base sólida.

Comecei com páginas estáticas, praticando estrutura HTML, CSS e navegação. Em projetos seguintes, evoluí para interfaces em React, dashboards em Python e uma API REST com Laravel.

Meu foco é desenvolver soluções que sejam funcionais, compreensíveis e documentadas, combinando experiência de uso com organização de código e dados.
